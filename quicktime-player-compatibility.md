# QuickTime Player compatibility

QuickTime Player in macOS can play various media containers, video codecs, audio codecs, and subtitle formats. Use this reference to determine format compatibility.

## Container formats

The following table lists container formats and their compatibility with QuickTime Player.

| Container | Compatibility |
| :--- | :--- |
| MP4 (`.mp4`, `.m4v`, `.m4a`, `.m4b`, `.m4r`) | **Yes** |
| QuickTime movie (`.mov`, `.qt`) | **Yes** |
| 3GPP and 3GPP2 (`.3gp`, `.3g2`) | **Yes** |
| Audio Interchange File Format (`.aif`, `.aiff`, `.aifc`) | **Yes** |
| Waveform Audio File Format (`.wav`, `.wave`) | **Yes** |
| Apple Core Audio Format (`.caf`) | **Yes** |
| Standalone FLAC (`.flac`) | **Yes** (macOS High Sierra 10.13 or later) |
| HTTP Live Streaming (`.m3u8`) | **Yes** |
| Material Exchange Format (`.mxf`) | **Yes** (requires Apple Pro Video Formats) |
| Matroska (`.mkv`, `.mka`, `.mks`) | No |
| WebM (`.webm`) | No |
| MPEG Transport Stream (`.ts`, `.m2ts`, `.mts`) | No |
| MPEG Program Stream and VOB (`.mpg`, `.mpeg`, `.vob`, `.evo`) | No |
| AVI (`.avi`) | No |
| Windows Media and ASF (`.wmv`, `.asf`, `.wma`) | No |
| Flash Video (`.flv`, `.f4v`) | No |
| Ogg (`.ogg`, `.ogv`, `.oga`, `.ogx`, `.opus`) | No |
| RealMedia (`.rm`, `.rmvb`, `.ra`) | No |
| DivX Media Format (`.divx`) | No |
| Musepack (`.mpc`) | No |
| WavPack (`.wv`) | No |
| True Audio (`.tta`) | No |
| Shorten (`.shn`) | No |
| DVD-Video (`VIDEO_TS`) | No (requires DVD Player in macOS) |
| Blu-ray Disc (`BDMV`) | No |

## Subtitles

The following table lists subtitle and caption formats and their compatibility with QuickTime Player.

| Format | Compatibility |
| :--- | :--- |
| QuickTime timed text (`tx3g`) | **Yes** |
| Closed captions (CEA-608 and CEA-708) | **Yes** |
| SubRip (`.srt`) | **Yes** (requires conversion to `mov_text` / `tx3g`) |
| SubStation Alpha (`.ass`, `.ssa`) | **Yes** (requires conversion to `mov_text` / `tx3g`) |
| WebVTT (`.vtt`) | **Yes** (requires conversion to `mov_text` / `tx3g`) |
| TTML, IMSC1, and SMPTE-TT (`.ttml`, `.xml`) | No |
| SAMI (`.smi`) | No |
| MicroDVD (`.sub`) | No |
| SubViewer (`.sub`) | No |
| PGS and SUP (Blu-ray bitmap) | No |
| VobSub and DVD Sub (IDX and SUB) | No |
| DVB Subtitles | No |
| XSUB (DivX bitmap) | No |
| Ogg Kate and Ogg Writ | No |
